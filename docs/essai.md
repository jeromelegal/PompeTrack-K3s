    subgraph "Kubernetes Core Services"
        ETCD["💾 etcd<br/>(State Store)"]

    subgraph "DNS Resolution"

    end
    
    %% External Traffic Flow
    Client -->|HTTP/HTTPS Request| TraefikLBL
    TraefikLBL -->|Route Match| Traefik
    Traefik -->|IngressRoute:<br/>Host Rule| ServiceVIP
    
    %% DNS Resolution
    Traefik -->|DNS Lookup| DNSQuery
    DNSQuery -->|Query Forwarded| CoreDNS
    CoreDNS -->|Watch Services| APIServer
    CoreDNS -->|Response| DNSResp
    DNSResp -->|Returns ClusterIP| ServiceVIP
    
    %% Service Routing with kube-proxy
    ServiceVIP -->|iptables Rule<br/>destination NAT| KubeProxy
    KubeProxy -->|Netfilter Chains| IPVS
    IPVS -->|Select Backend| PodA
    
    %% Pod Destination - Calico Network Policy Check
    IPVS -->|Traffic Arrival| NPProd
    NPProd -->|Policy Evaluation:<br/>Source/Dest Labels| PodA
    
    %% Traffic Enters Envoy Sidecar
    PodA -->|iptables Redirect<br/>Port :15001| EnvoyA
    
    %% Inter-namespace Communication Path
    EnvoyA -->|Connect to<br/>Production->Staging| NPCross
    NPCross -->|Cross-namespace<br/>traffic allowed| PodB
    
    %% mTLS Handshake
    EnvoyA -->|mTLS Handshake| mTLSHandshake
    mTLSHandshake -->|Verify Certificates| CertStore
    CertStore -->|Signed by| CA
    CA -->|Generated by| Istiod
    
    %% Authorization Check
    mTLSHandshake -->|Verify SA identity<br/>from cert| AuthPolicy
    AuthPolicy -->|Check allowed<br/>source SA| SAA
    AuthPolicy -->|Check allowed<br/>dest SA| SAB
    
    %% DNS and ServiceAccount Integration
    APIServer -->|Maintain| ETCD
    Istiod -->|Watch for<br/>cert rotation| APIServer
    
    %% Traefik Dashboard
    Traefik -.->|Dashboard at<br/>dashboard.localhost| Traefik
    
    %% Request to actual container
    EnvoyB -->|localhost:8080| AppB
    
    %% mTLS encrypted connection
    EnvoyA -->|Encrypted<br/>mTLS| EnvoyB
    
    %% Application response
    AppB -->|Response| EnvoyB
    EnvoyB -->|Decrypt & Send| EnvoyA
    EnvoyA -->|Response| ServiceVIP
    ServiceVIP -->|Response| Traefik
    Traefik -->|HTTP Response| Client
